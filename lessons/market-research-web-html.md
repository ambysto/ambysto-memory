For market research, produce an HTML report and provide a URL that opens directly in a browser, not only a downloadable file.
Prefer the currently authorized project repository's static hosting (for example, GitHub Pages) and preserve sources, tables and charts in the page.
Confirm the published URL opens the intended report before handoff.
Do not create a hosting account or publish sensitive/private material; if no approved web destination is available, explain the blocker and ask how to expose it.
